# Лучшие практики и эталонные шаблоны кода (Best Practices & Snippets)

В этой папке хранятся эталонные куски кода (сниппеты) и проверенные паттерны разработки, которые мы используем в проекте. 
Они служат "золотым стандартом" — именно так должен быть написан любой новый код.

**Что здесь хранится:**
* **Правильные способы отправки транзакций:** `send_limit_order.lua`, `send_stop_order.lua`, `send_bracket_order.lua`.
* **Снятие заявок:** `kill_stop_orders.lua`.
* **Паттерны получения позиций и балансов:** `get_position_depo.lua`, `pos_transfer.lua`.
* **Логирование:** `write_log.lua`.
* **Межпроцессная синхронизация через файлы:** `file_semaphore_patterns.md`.
* **Защита от старых сделок при реконнекте:** `alltrade_reconnect_filter.lua`, `alltrade_reconnect_filter.md`.
* **Эталонные циклы и проверки:** любой другой бойлерплейт, который нельзя писать "отсебятиной".
