# TODO: Привести сниппеты к единой структуре

## Задача

Каждый функциональный сниппет (например, send_limit_order.lua, send_stop_order.lua) должен быть дополнен отдельными файлами-примерами, показывающими, **где и как** в реальном коде происходит переключение флага-переключателя (pendOrder, pendStop и т.д.).

## Целевая структура

Для каждого сниппета создать набор файлов:

### 1. Основной файл (send_limit_order.lua)
Содержит сам код функции и объявление флага-переключателя.
Комментарий к флагу нейтральный: переключение происходит вне этого файла.

### 2. Пример сброса в OnOrder (example_pend_reset_on_order.lua)
Короткий пример -- только тело коллбэка OnOrder без main() и прочего.
Показывает, как флаг сбрасывается при получении подтверждения от торгового сервера.

### 3. Пример сброса в main() (example_pend_reset_main.lua)
Пример или описание: как флаг управляется прямо в цикле main(),
например через проверку состояния таблиц QUIK (getItem, getNumberOf).

### 4. Пример сброса в OnAllTrade (example_pend_reset_on_all_trade.lua)
Пример: как флаг сбрасывается при движении цены (в тиковом коллбэке),
когда алгоритм цено-зависимый.

## Примечания
- Примеры должны быть короткими и изолированными -- только суть, без boilerplate.
- OnStopOrder не использовать как место сброса: может возвращать nil (ненадежен).
- Структура "сделай сейчас -- исправим потом". Создать черновые версии, потом уточнить.
