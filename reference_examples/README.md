# Эталонные примеры и модули (Reference Examples)

Эта папка содержит эталонные скрипты и примеры работы модулей для QLUA роботов.

---

## 1. dministrator_stucks.lua — Администратор отслеживания позиций (Акционные депозитарные лимиты)

### Назначение скрипта
Скрипт dministrator_stucks.lua представляет собой сервисный модуль (администратор позиции), который в бесконечном цикле каждые 500 мс считывает текущий статус открытой позиции по инструменту фондовой секции (акции) и записывает результаты в текстовый файл 	otalpos.txt.

### Структура и переменные скрипта

#### Глобальные переменные окружения:
- sec_code ("SBER") — код торгового инструмента (акции).
- class_code ("QJSIM") — класс инструмента (демо/фондовый рынок).
- irm_id ("NC0011100000") — идентификатор фирмы / торговый счет.
- client_code ("1003") — код клиента в системе QUIK.
- 	rdaccid ("NL0011100043") — торговый счет депозитарного учета.
- ile — путь к текстовому файлу выгрузки текущего состояния позиции (getScriptPath().."\\totalpos.txt").

---

### Функции скрипта

#### 1. getPosition(sec_code, trdaccid)
Эталонная функция получения позиции на фондовом рынке из таблицы depo_limits.

**Логика работы:**
1. Вызывает getNumberOf("depo_limits") для получения общего количества записей в системной таблице лимитов по бумагам.
2. В цикле проверяет каждую строку таблицы getItem("depo_limits", i) по условиям:
   - Совпадение кода тикера ow.sec_code == sec_code
   - Совпадение торгового счета ow.trdaccid == trdaccid
3. Находит строку с наибольшим limit_kind > 0 (актуальный режим расчетов Т2 / Т+).
4. Извлекает:
   - esult_currentbal — текущий остаток бумаг в позиции (ow.currentbal).
   - esult_wa_price — средневзвешенную цену приобретения позиции (ow.wa_position_price).
5. **Возвращает 3 значения:** limit_kind, result_currentbal, result_wa_price. Если позиция не найдена или пуста, возвращает 
il, nil, nil.

#### 2. posTRSFr(text)
Вспомогательная функция записи форматированной строки в файл 	otalpos.txt.
- Открывает файл ile в режиме перезаписи ("w").
- Записывает строку 	ext и завершает перевод строки (\n).
- Закрывает файловый дескриптор.

#### 3. main()
Основной цикл скрипта:
- Каждые 500 мс вызывает getPosition(sec_code, trdaccid).
- Если позиция существует (limit_kind ~= nil), формирует строку 	ext в формате: "<sec_code> <currentbal> <wa_price>".
- Вызывает posTRSFr(text) для обновления файла 	otalpos.txt.
- Делает паузу sleep(500).

---

### Значение возвращаемых параметров getPosition:
- limit_kind — тип лимита (1 — Т0, 2 — Т1, 3 — Т2 и т.д.). Позволяет определить режим расчетов.
- currentbal — число бумаг в портфеле (положительное для лонга, 0 при отсутствии позиции).
- wa_price — средневзвешенная цена позиций, используемая для отсчета Тейк-Профита и Стоп-Лосса.
