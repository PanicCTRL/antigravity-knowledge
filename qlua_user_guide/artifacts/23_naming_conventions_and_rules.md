# Правила разработки и словарь переменных (Clockwise Naming & Dictionary)

Этот документ содержит стандарты кодирования, именования и подробный словарь (dictionary) всех переменных, используемых в проекте Clockwise.

---

## 1. Системные переменные QUIK (Правило 8.5)
Имена берутся строго из официальной документации QUIK. Оставляем только 5 ключевых переменных. Остальные можно получать из документации или дампов при необходимости.

| Название переменной | Описание |
| :--- | :--- |
| `sec_code` | Код инструмента / бумаги (например, `"NGJ6"`, `"SBER"`) |
| `class_code` | Код класса инструментов (например, `"SPBFUT"`, `"QJSIM"`) |
| `firm_id` | Идентификатор фирмы / Торговый счет для срочного рынка (например, `"SPBFUT"`) |
| `client_code` | Код клиента (например, `"762157N"`) |
| `trdaccid` | Торговый счет для фондового рынка (например, `"NL0011100043"`) |

---

## 2. Переменные времени / Интервалов (Правило 8.4)
Именуются в стиле `snake_case` из двух слов, где второе слово — `time` или `length`.

| Название переменной | Описание |
| :--- | :--- |
| `period_length` | Длительность торгового периода в секундах (по умолчанию `60`) |
| `reset_before` | Секунд до конца периода для фазы сброса/ожидания (по умолчанию `20`) |
| `all_end_period` | Метка времени (`os.time()`) окончания текущего периода |
| `first_period_end` | Метка времени (`os.time()`) окончания 1-й фазы торгового периода |
| `trade_hour` | Час торгов (из старой логики `ClearTime`) |
| `trd_min_befor` | Минута граница сброса в часовом периоде (по умолчанию `45`) |

### Флаги состояния робота (Boolean)
| Название переменной | Описание |
| :--- | :--- |
| `opn` | `true` если позиция сейчас открыта |
| `stopRpcd` | `true` если стоп-лосс в текущем периоде уже перенесен |
| `pendOpen` | `true` пока отправлена заявка на вход, но ещё не исполнена |
| `pendStop` | `true` пока отправлен стоп-лосс, но подтверждения нет |
| `pendBrkt` | `true` резервный флаг для брекет-заявки |
| `pendKillOrder` | `true` флаг процесса снимка/снятия стоп-заявок |

## 4. Функции проекта

### 4.1. Локальные функции основного скрипта (Правило 8.7 — PascalCase)
| Функция | Назначение |
| :--- | :--- |
| `Clockwise()` | Возвращает стейдж периода (1 — активность/вход, 2 — сброс/ожидание, 0 — сброс периода) |
| `CountDecimals(n)` | Вычисляет количество знаков после запятой у числа |

### 4.2. Функции во внешних файлах (Правило 8.8 — snake_case из 2–3 слов)
| Функция | Назначение |
| :--- | :--- |
| `ClearTime()` | Парсит `SERVERTIME` из QUIK и возвращает `hour, minute, second` |
| `CanIOpenTrade()` | Выполняет комплексную проверку разрешения торговли |
| `CheckConnection()` | Проверка флага соединения с сервером QUIK |
| `CheckTradingStatus()` | Проверка статуса инструмента (`"торгуется"`) |
| `CheckTradingDay()` | Проверка на выходные дни |
| `CheckPriceLimits()` | Проверка расстояния до верхних/нижних планок |
| `KillStop()` | Снимает все активные стоп-заявки по инструменту |
| `SendKill()` | Ищет в `stop_orders` и отправляет транзакции снятия |
| `WriteLog(path, text, noPrefix)` | Записывает строку в текстовый лог |
| `Entry(sec_code, class_code)` | Отправляет рыночную/лимитную заявку на вход |
| `SendStop(sec_code, class_code)` | Выставляет стоп-лосс по `startPrice` и `price_limit` |
